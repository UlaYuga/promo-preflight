## 7. Регуляторные изменения 2025 — главное

### APAC: "экономическое удушение"
Малайзия (расширение блокировок iGaming в соцсетях, ответственность платформ), Индия (полный запрет онлайн-игр с реальными деньгами, налог 30%+1% TDS), Южная Корея (запрет анонимных кошельков, VASP лицензирование).

> Драпий (DS Solutions): "Наиболее эффективным механизмом стало экономическое удушение вместо технических блокировок. Жёсткое ограничение платёжного трафика, санкции против рекламных посредников и аффилиатов, белые списки для поисковых систем."

### LATAM: фискализация + цифровой контроль
- **Бразилия**: Нормативный Акт SPA/MF #3 + Технический Норма SEI SEI/MF #229 + Приказ SPA/MF #566 + Приказы SPA/MF #1.885/2025 + MESP #31 + SPA/MF #338/2025 + Приказ MESP #36 + Вступление Google Brasil в Conar + Приказы SPA/MF #2.217/2025 + Обязательные правила для банков + Приказ SPA/MF #2.579/2025 + #31/2025 + Законопроект PL 5473/2025 + Нормативный Акт #2299. **Главное для нас**: "ограничения на промо и бонусы, повышение налоговой нагрузки, необходимость адаптации бизнес-планов"
- **Аргентина**: Постановление #13510 (Кордова), Резолюция DGR 23/2025 (Мисьонес), Постановление 1755/25 + куча локальных приказов. **Главное**: "фрагментированное регулирование на уровне провинций и муниципалитетов, необходимость быстрой адаптации к локальным правилам"
- **Колумбия**: временный налог на депозиты игроков, Резолюция #20250022644
- **Мексика**: Циркуляр 1/2025 Банка Мексики (SPEI), обновление закона о защите персональных данных (LFPDPPP), поправки к LFPIORPI (AML), налоговая реформа IEPS
- **Чили**: Закон 19.995, законопроект Boletín №14.838-03

### EU: барьеры входа, AML/KYC, фискализация
- **UK**: новый RTS, обновление UKGC лицензирования, госсбор на азартные игры, **ограничение ставок в онлайн-слотах**, повышение налога на remote gambling
- **Германия**: фрагментация по землям (Баден-Вюртемберг), федеральный суд 8C 3.24
- **Италия**: Закон о бюджете 2025, План ADM 2025-2027, **новые правила для личных лимитов на депозиты и ставки**, Декрет №41/2024
- **Польша**: ужесточение AML, законопроект приравнивает лутбоксы к азартным играм

## 13. Итог: что это значит для Preflight

### Реальный pain клиентов 01.tech (это и есть pain story для README)

Клиент 01.tech — оператор, который:
1. Работает на **множестве рынков** одновременно (LATAM + APAC + AFR + CIS + MENA + EU)
2. **Каждый квартал** видит новые регуляторные изменения в нескольких юрисдикциях одновременно
3. Должен **быстро адаптировать** промо/лендинг/креатив/T&C/payment-flow под каждый новый рынок
4. Боится **локальных блокировок** (это сейчас #1 риск 2026)
5. Использует **crypto + fiat** в разных пропорциях по регионам
6. Запускает кампании в **связке с провайдерами** (Pragmatic Play турниры, эксклюзивы)
7. Работает с **аффилиатами + стримерами + инфлюенсерами** — каждая связка отдельный compliance-риск
8. Локализует **глубоко** (не перевод, а культурный код) на 8-15 языков

### Что Preflight решает в этом контексте

**Pre-launch readiness check для multi-jurisdiction iGaming операторов.**

Перед каждым запуском (или ребрендингом, или ребалансом промо) — прогон через 11 deterministic чеков:

1. **Channel consistency** — без изменений
2. **Jurisdictional T&C completeness** (было: terms robustness) — checks per region
3. **Offer math sanity** — без изменений
4. **Jurisdictional risk signals** — расширенный: запрещённые формулировки per region ("risk-free" UK, "guaranteed" UK, "bonus без условий" Brazil...)
5. **Localization depth QA** — currency + payment methods + RG wording + age (18/21) + cultural references parity
6. **Launch ownership** — без изменений
7. **Link QA** — расширенный: geoblock проверка домена для запрещённых regions
8. **Format QA** — без изменений
9. **🆕 Payment compatibility** — методы оплаты в копии vs доступные в targeted region
10. **🆕 Crypto disclosure** — упомянута крипта → check region rules (Россия обязательно, Алжир никогда, Турция серый)
11. **🆕 Mobile-first format** — для mobile-first рынков (Россия 64%, выше в APAC) — креатив адаптирован
12. **🆕 (если время) Provider co-promo check** — если в копии указан провайдер (Pragmatic, Evolution) — корректно ли указаны условия партнёрской акции

### Регуляторные требования по T&C clauses (готово к подстановке в YAML)

- **Spain DGOJ** (Real Decreto 958/2020): обязательно "18+", запрет ассоциировать gambling с "успехом, счастьем, финансовой выгодой". Запрещены "sin riesgo", "asegurado"
- **Germany GGL**: бонусы только при регистрации (sign-up only), нельзя размещаться рядом с illegal gambling рекламой
- **Curaçao LOK** (с 2026): T&C "в один клик", checkbox согласия игрока, запрет одностороннего изменения условий
